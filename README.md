# Road Tech Rental — Аренда дорожной и строительной техники по всей России

Федеральный коммерческий каталог и конверсионный лендинг для привлечения заказчиков из Яндекс.Директа на аренду тяжелой и специализированной техники:

- **Автомобильные и вездеходные краны Zoomlion (до 600 тонн):** ZRT850, ZRT1100, ZTC800, ZTC1000, ZTC1500, ZAT1200, ZAT1600, ZAT2000, ZAT3000, ZAT3500, ZAT6000;
- **Гусеничный экскаватор Hitachi ZX 200LC-5G:** ковш 1.2 м³, глубина 6.67 м, радиус 9.92 м, гос. номер `0616 MX 77` (негабаритная колея, быстрая подача по Москве в габарите);
- **Кран-манипулятор (КМУ 7 тонн):** перевозка бытовок, оборудования, стройматериалов;
- **Монтаж дорожного барьерного ограждения:** установка отбойников 11ДО/21ДО по ГОСТ с применением КМУ и сваебойного оборудования;
- **Дорожные фрезы Wirtgen (W 130 CF):** холодное фрезерование асфальта с оператором и нивелировкой;
- **Кохеры для литого асфальта:** термосы-бункеры 5-10 тонн для ямочного ремонта.

## Локальный просмотр

Сайт не требует сборки. Запустите любой локальный статический сервер из этой папки и откройте `index.html` через его адрес. Прямое открытие файла тоже работает, но локальный сервер точнее повторяет GitHub Pages.

## Настройка контактов и заявок

Откройте `assets/js/config.js` и заполните:

```js
const SITE_CONFIG = {
  leadEndpoint: "https://адрес-worker.example/lead",
  phone: "+7 (999) 000-00-00",
  telegram: "https://t.me/username",
  whatsapp: "https://wa.me/79990000000",
  metrikaId: "12345678"
};
```

`leadEndpoint` должен принимать `POST` с JSON. Telegram Bot Token хранится только в секретах Cloudflare Worker и никогда не добавляется в этот репозиторий.

Если `leadEndpoint` пустой, сайт честно показывает диагностическое сообщение и не имитирует успешную заявку. При ошибке поля не очищаются.

## Данные заявки

Форма отправляет:

- `name`;
- `phone`;
- `service`;
- `page_url`;
- `page_title`;
- `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`;
- `yclid`;
- `timestamp`.

## Яндекс.Метрика

После заполнения `metrikaId` автоматически подключается счётчик и становятся доступны цели:

- `phone_click`;
- `form_start`;
- `form_submit`;
- `calculate_click`;
- `freza_lead`;
- `frezerovanie_lead`;
- `koher_lead`;
- `litoi_asfalt_lead`.

## GitHub Pages

1. Создайте новый репозиторий только для этого проекта.
2. Загрузите содержимое папки `road-tech-rental` в корень репозитория.
3. В настройках репозитория откройте **Pages**.
4. Выберите публикацию из ветки `main`, папка `/root`.
5. После появления адреса проверьте формы, изображения и переходы с UTM-метками.

Все пути на сайте относительные, поэтому он работает в подпапке GitHub Pages и после подключения собственного домена.

## Домен и SEO перед публикацией

Когда домен станет известен:

1. замените `https://example.invalid/road-tech-rental/` в `sitemap.xml`;
2. добавьте абсолютный `canonical` в `<head>` каждой готовой страницы;
3. добавьте абсолютный `og:url` и `og:image`;
4. добавьте строку `Sitemap: https://ваш-домен/sitemap.xml` в `robots.txt`;
5. снимите `noindex` с посадочных страниц только после их полного наполнения.

## Новая посадочная страница

Скопируйте папку одной из подготовленных страниц, поменяйте `title`, `description`, H1 и `data-service`. Подключайте общие файлы через `../assets/css/style.css`, `../assets/js/config.js` и `../assets/js/main.js`.
